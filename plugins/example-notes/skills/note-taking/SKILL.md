---
name: Note taking
description: How to keep tidy notes in the local notebook (titles, dates, one topic per note).
---

Use the notebook tools from the Notes plugin.

1. Before writing, call `notes__list_notes` and reuse an existing note when the topic matches; append instead of creating a near-duplicate.
2. Note titles are short and specific, e.g. `meeting 2026-11-09` or `reading list`.
3. Start every entry with the date (YYYY-MM-DD) on its own line.
4. Keep one topic per note. Put decisions first, open questions last.
5. Never delete a note unless the user asked for it by name.
