# 任务栏图标：要求说明

> 纯描述，写的是要做成什么样，不涉及实现。造型以同目录上一级的 `svg/spica-taskbar-dark.svg`、`svg/spica-taskbar-light.svg` 为准。

## 1. 常驻图标（程序运行时的任务栏 / Alt-Tab）

- **形状**：无底的九芒花，不加圆角底。
- **跟随任务栏深浅**：
  - 深色任务栏用白花（#F1F5F9）。
  - 浅色任务栏用近黑花（#0F172A）。
  - 以任务栏颜色为准。Windows 里任务栏和应用的深浅可以分开设置。
  - 系统切换深浅时立刻换图标，不用重启。
- **造型**：用小尺寸专用的「光学版」，比应用内的花更大，瓣更宽，轴心更大，保证 16–32px 下依然清楚。
- **启动**：一打开就显示用户上次的图标（含自定义配色）。不要先闪一下出厂图标再切换。
- **和应用内的花无关**：这里的设置只影响任务栏和 Alt-Tab，应用左上角的花不受影响。

## 2. 配色设置（设置 → 外观 → 任务栏图标配色）

三选一。每个选项旁边放实时预览，深浅任务栏各一张；预览图和真正交给任务栏的图必须是同一份。

1. **单色（默认）**：整朵花一个颜色，随任务栏变黑或变白。
2. **跟随皮肤强调色**：三片长瓣（12、4、8 点钟方向）用当前皮肤的强调色，其余随任务栏变黑或变白。换皮肤时跟着变。
3. **自定义**：给 9 片瓣和轴心逐个上色。

### 自定义编辑器

- **选中**：
  - 显示一朵放大的花，点瓣或轴心即可选中，可以多选，选中的部分用虚线描边标出。
  - 提供快捷选择：全部长瓣、全部短瓣、全部瓣、轴心。
- **上色**：可选「文字色」「强调色」或取色器里的任意颜色。
  - 文字色：随任务栏变黑或变白。
  - 强调色：随皮肤变化。
  - 任意颜色：深浅任务栏下都显示同一个颜色。
- **样板（一键填入）**：

  | 样板 | 配色 |
  |---|---|
  | 定稿 | 长瓣用强调色，其余用文字色 |
  | 短瓣强调色 | 短瓣用强调色，长瓣和轴心用文字色 |
  | 单色 | 全部用文字色 |
  | 乱序彩色 | 用户偶得的一组，按顺序为：强调色、#F5B942、文字色、#A78BFA、#E12885、#39C5BB、#FF6B6E、文字色、#4CC57E，轴心用文字色 |
  | 青粉交替 | 青 #39C5BB 和粉 #E12885 交替，每第三片用文字色，轴心用青 |
  | 七彩渐变 | 九片瓣的色相每片相差 40°，饱和度、亮度都一样，轴心用文字色 |
  | 缤纷 | 按下面的配色原理，以当前皮肤的强调色为起点生成 |
  | 随机生成 | 每次随机一个起始色相，再随机选一种同样满足缤纷原理的排列 |

- **缤纷的配色原理**：
  - 九个颜色的色相等距，每 40° 一个。
  - 以起点色相为轴，左右镜像排布。
  - 三片长瓣在 0°、+120°、−120°，构成三分色骨架。
  - 九个颜色的亮度和饱和度相同，只有色相不同。
  - 相邻两片瓣的色相差至少 80°。
- **导入 / 导出**：
  - 一行 10 项的数组文本，可以粘贴填入，也可以导出当前配色。
  - 顺序：从 12 点钟起顺时针 9 片瓣，其中第 1、4、7 片是长瓣，最后一项是轴心。
  - 每项写 `ink`（文字色）、`accent`（强调色），或任意 CSS 颜色。
  - 格式看不懂时，用人话提示哪里不对。

## 3. 状态灯（提示 Agent 的结果）

- **位置**：在图标右下角画一个小圆点。不用系统的叠加图标位，因为 Windows 11 把它放在了右上角。
- **三种状态**：
  - **琥珀**：有 Agent 正在等你确认或回答，一直亮到你处理完。
  - **绿**：某个 Agent 会话跑完了。
  - **红**：Agent 被停止，或者工具出错。
  - 绿和红只在窗口不在前台时才亮，亮的同时任务栏按钮闪一下；切回窗口立即清除。
  - 你正看着窗口时，不需要提醒。
- **优先级**：等确认 > 出错 > 完成。
- **运行中不动任务栏**：应用内那朵花已经在动，用来表示运行中。
- **颜色**：取当前皮肤的语义色，琥珀对应警告色，红对应错误色，绿对应成功色。
- **圆点几何**（以 24px 图标计）：
  - 圆点直径 8px，圆心在 (21.5, 21.5)，压出图标边缘 3px。
  - 圆点外挖一圈 1.5px 的透明环，把点和花隔开。
  - 只在有圆点时，把整朵花缩到约 94%，给圆点让位。
  - 没有圆点时，花保持满尺寸。
  - 已否决的方案：砍短右下那片长瓣来留缺口。否决原因是常驻时九瓣会不对称。
- **启动时不带旧圆点**：带圆点的图标不能当作下次启动时的初始图标。

## 4. 写死在文件里的图标（`spica.ico`）

- **用在哪里**：安装程序的窗口图标和右上角头图、资源管理器里的 exe（安装版和便携版）、卸载条目（「应用和功能」）。这些位置的图标写死在文件里，不能随任务栏深浅换色。
- **样子**：单色花直接画在透明底上，不加底板、不加描边、不加阴影（2026-11-10 定，原话「去掉描边和外圈暗色光晕。花直接画在透明底上，不加底板、不加阴影。」）。
  - 所有尺寸都用第 1 节的光学版花，每个尺寸单独画，不从大图缩。
  - **颜色：待定**。这些位置跟不了系统深浅，白、近黑、蓝各有看不见的地方，三选一等他定；定之前成品先用白 `#F1F5F9`。
  - 已作废：深色圆角磁贴底；「黑边白花」（白花加一圈深色细边，小尺寸下细边把瓣缝填满，糊成一团）。
- **任务栏按钮、开始菜单和固定到任务栏的快捷方式**：随任务栏深浅换白花或近黑花、不带边（2026-11-10 定，原话「浅色主题用黑花 暗色主题用白话，全部选用无边的那种设计」）。程序运行时按深浅上色、生成图标，再把这几个快捷方式改指过去；逐帧蒙版见 `files.md` 的 `png/spica-taskbar-*.png`。桌面快捷方式不改指，仍显示 `spica.ico`。
- 程序打开之后，任务栏图标换成第 1 节的常驻图标。
