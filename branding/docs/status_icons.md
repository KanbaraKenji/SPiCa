# 带圈状态图标

完成图标（带圈对钩）的要求见 `check_icon.md`。这一族其他八个按它的画法补齐，2026-11-10 定稿，九个都用。

## 共同的画法

- 24×24 网格，圆圈圆心 (12, 12)、半径 9.5。
- 线宽 2.5，比菜单、按钮这类操作图标粗；端点和拐角圆头（只有完成图标圆圈的断口是切角）。
- 单色，颜色取皮肤的语义色，换皮肤跟着变。
- 常用尺寸 15–16px，跟在文字旁边。

## 九个状态

| 名字 | 什么时候用 | 图形 | 颜色 |
|---|---|---|---|
| `done` 完成 | 任务、步骤完成，测试通过 | 对钩（他给的原件） | 成功色 |
| `running` 进行中 | 正在运行 | 淡色底环上一段四分之一亮弧，亮弧绕圆心转（一圈 1 秒；减弱动效时不转） | 强调色 |
| `warning` 警告 | 需要注意，但没有失败 | 感叹号 | 警告色 |
| `error` 错误 | 失败、出错 | 叉 | 错误色 |
| `waiting` 等待确认 | 等用户允许一个操作 | 时钟指针 | 警告色 |
| `question` 提问 | 等用户回答问题 | 问号 | 警告色 |
| `stopped` 已停止 | 用户手动停止、工具被中止（不是出错） | 实心小方块 | 次要文字色 |
| `queued` 排队 | 还没开始的步骤 | 九段虚线圈，圈里不画东西 | 次要文字色 |
| `info` 提示 | 中性的提示 | 字母 i | 强调色 |

等待确认和提问都是「在等你」，颜色一样，形状分开。

## 不进这一族的

确认卡标题的盾牌、设置齿轮、关闭的叉、删除、发送、展开这类是**操作或类别**，不是状态，保持操作图标的常规粗细。尤其关闭按钮的「×」和错误状态的「带圈 ×」要分开，不然按钮看着像报错。

## 在应用里使用

```tsx
import { SpicaStatusIcon } from '@spica/brand/react';

<SpicaStatusIcon name="done" size={16} />      // 颜色自动取皮肤的成功色
<SpicaStatusIcon name="running" size={16} />   // 亮弧会转
```

- 颜色来自 `@spica/brand/styles.css` 里的 `status.css`；调用处设了 `color` 就以调用处为准。
- 字符串版 `statusIconSvg(name, { size, color })` 给主进程和导出脚本用。
- 素材里的单个 SVG（`icons/spica-<名字>.svg`）由 `npm run brand:build -w @spica/brand` 从同一份代码生成；`spica-check.svg` 是原件，脚本不覆盖。界面不要各自再画一套。
