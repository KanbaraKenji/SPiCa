# Spica 标志动效

标志是纯 SVG，所有动效都是 CSS 关键帧，不需要外部软件；随皮肤变色、适配缩放，并遵守系统「减少动态效果」设置。

- 样式：`packages/brand/src/styles/mark.css`（入口 `@spica/brand/styles.css`）
- 组件：`<SpicaMark state="…">`，组件给 `<svg>` 挂 `spica-mark--<state>`

## 铁律

任何状态下**标志轮廓一像素不动**：动效只动位置、透明度、整体旋转和缩放，不切割、不变形。

## 状态

| state | 场景 | 动作 |
|---|---|---|
| `think` | 等模型生成答复 | **炸开**：瓣向外散开再合拢，星屑从花心飞出，1.7s 一轮 |
| `busy` | 正在流式回复 | **追光**：九片瓣顺时针轮流亮暗 |
| `tool` | 调用工具中 | **咔 120°**：先往回蓄力，再整体转 120°；三片长瓣 120° 对称，循环无缝 |
| `await` | 等工具答复、等人确认 | **脉冲**：轴心向外放两道涟漪，涟漪经过时瓣轻胀 |
| `done` | 完成那一下 | **转一整圈**（一次性） |
| `work-1` / `work-2` / `work-3` | 左上角常驻，后台有任务在跑 | 按负荷分三档：1 档轴呼吸；2 档加三片长瓣星闪；3 档九片全闪、轴变强调色 |
| `idle` | 其他时候 | 静止 |

负荷怎么算由使用方决定（例如并发对话数 + 后台任务数），组件只接档位。

## 点击（`tappable`）

- 每点一下：整体转 120°，轴弹一下、放一圈涟漪。
- 每第三下：一圈冲击波，长瓣闪一下 accent lock 色。
- 累计 39 下起：**accent lock**，长瓣常驻 `--spica-accent-lock`（缺省 `#39C5BB`）。组件触发 `onAccentLock` 回调，要不要记住由使用方决定；也可以用 `accentLocked` 直接控制。

## 回答末尾的状态行

对话忙碌时，状态行接在最后一轮正文末尾：「标志动效 + 本轮计时 + 阶段文案」（思考中… / 正在回复… / 正在调用 X… / 等你确认 X…）。完成后停留约 1.4s，播 `done` 再收起。计时从本轮用户消息发出算起。

## 开机画面：暗处亮起 · 双星环绕

组件 `<SpicaSplash ready={…} onDone={…} theme="dark|light" orbitPeriod={…} caption="v0.1.0" />`，铺满父元素。时间线是纯函数，在 `packages/brand/src/splash.ts`（`splashFrame()` 给出任一时刻的画面状态，`starfield()` 给出背景星点），组件按帧把状态写到 SVG 和画布上。

花标和字标排成大横标居中，花标约占画面高度的 36%；画面是 1280 × 720 的舞台，按窗口等比缩放。

**节拍**：背景星点每颗从中心飘到画面外固定 5 秒（`SPLASH_TIMING.starfieldPeriod`）；双星转一圈 3.5 秒（`SPLASH_TIMING.orbitPeriod`，组件参数 `orbitPeriod`）。字标的起伏按半圈一拍。

**双星轨道**：像真正的双星一样，两颗星绕共同的中心（花心）转，永远一前一后、相差半圈。轨道是开普勒椭圆（`SPLASH_ORBIT`：半长轴 32 个花标局部单位，花心在焦点上），近快远慢，快慢比 `speedRatio` 缺省 2。轨道平面倾斜，最近点朝前：星在前面时又快、又大、又亮，画在花标上面；在后面时慢、小、暗，被花标挡住（花瓣下面垫一层底色剪影）。

**加载中的花和字**：花标九片瓣同一个亮度，跟双星同一个节拍（半圈一拍）呼吸；轴心半透明（约 42%～52%，随呼吸微变），合心那一刻才变实；字标五个字母按同一节拍像波浪一样起伏。花和字都不和星的位置一一对应。双星加载中就带一条短而淡的拖尾。

**收尾顺序（定死）**：ready → 加速扩轨（带拖尾）→ 大半径上绕约 0.94 圈 → 大半径段一结束（此时前面那颗星在字标一侧），双星从当时位置各沿一小段短弧直接扎进花心（不再有收心螺旋）→ 细环先行填充 → 扫字 → 停 → 淡出。

**收尾时间表**（`SPLASH_FINISH` 是每一步的时长参数，`splashSchedule()` 算出各步起止；下表是缺省值，从 ready 算起。真实运行里 ready 一到就进收尾；评审视频用 7 秒模拟加载，所以大半径段在视频第 8.7 秒结束、第 9.05 秒扎进花心）：

| 步骤 | 开始 | 用时 |
|---|---|---|
| ① 加速扩轨：转速 1 → 3 倍，轨道放大到 1.8 倍，拖尾拉长变浓 | 0s | 0.6s |
| ② 大半径上绕约 0.94 圈（3 倍转速），结束时前面那颗星在屏幕右侧（字标一侧）。真实运行里加载完成的时刻是随机的，圈数会在 0.94 上下半圈内按 ready 时刻微调，保证总由同一颗星、从同一方位扎进去（`alignDive` 缺省开；方位 `diveAngle` 缺省 92° 即字标一侧，领头星 `diveStar` 缺省白色伴星；对比档 B 是 `bigTurns: 0.5`、`diveAngle: 72`、`diveStar: 'primary'`：蓝星在前面、走到字标右上方时从右侧扎入；圈数很少时若微调后不足 0.05 圈会补一圈） | 0.6s | 约 1.1s（±0.58s） |
| ③ 扎心：从字标一侧直接扎进花心；转速按 (1-x)² 衰减到 0，只走一小段短弧；半径缓入、越扎越快 | 1.7s | 0.35s |
| 双星合于花心、消失；轴心由半透明变实 | 2.05s | 轴心 0.25s |
| ④ 填充（C 细环先行）：两道细环先扩出去，实色随后从花心跟上；轴弹一下 | 2.05s | 1.2s（轴 0.5s） |
| 背景星点：一路缓入加到 3 倍，合一后平滑回落 | 0s / 2.05s | 2.05s / 1.5s |
| ⑤ 扫字：光斑从左到右掠过字标，字由暗变亮、闪一下辉光 | 3.1s | 0.8s |
| 字的辉光回稳 | 3.9s | 0.5s |
| ⑥ 停住 | 4.4s | 1.0s |
| ⑦ 整层淡出，然后回调 `onDone` | 5.4s | 0.4s |

背景星点的放射透视点在窗口正中央（不是花心）；穿过花标区域时被花标挡住。

ready 到整层消失共约 5.8 秒（`SPLASH_FINISH_AFTER`）。浅色版同样的步骤，但不画花心光晕、星的光晕；字的辉光在浅色里是一层清晰的强调色盖在字上，不用模糊（不糊成脏底）。

**跳过**：`skippable` 缺省开，点一下或按任意键，开机画面 0.25 秒淡出后回调 `onDone`（完整版、短版都可以跳）。

**短版**（`mode="brief"`，每天第二次打开起由外壳切换）：完整横标淡入 0.3s、停 0.4s、淡出 0.3s，共 1 秒，不放星点；1 秒到了还没 ready 就停在完整横标上等。时长在 `SPLASH_BRIEF`。

| 段落 | 动作 |
|---|---|
| 背景（一直在） | 星点从窗口正中央沿径向飘出屏幕，带短光迹，5 秒一程；四分之一用强调色 |
| 进场 0.2～1.0s | 花和字从暗处浮现 |
| 加载中（循环） | 一蓝一白两颗星在倾斜的开普勒椭圆上绕花标转，3.5 秒一圈，前面快后面慢；花和字同节拍呼吸 |
| 收尾 | 见上面的时间表 |

任何时刻 ready，收尾都从当前位置接上，不跳帧。Spica 是一对蓝白双星，所以星是一蓝（强调色）一白。

**配色**：暗色底 `#0B0F19`，四角稍压暗，花心和星带淡淡的蓝色光晕，蓝星强调色、伴星近白。浅色底 `#F7F9FC`，纯色不压暗角，星点用浅蓝细线，**不画任何光晕**（花心光晕、星的光晕整层不画，浅底上会显成一团脏色）；双星是实心的，蓝星用强调色（中蓝），伴星用深蓝 `#1B3F7A`，内核和星同色、不挖空。

**预览**：`npm run preview:splash -w @spica/brand -- <输出目录> [dark|light]`，用 Vite 打包 `packages/brand/demo/splash.html`，在 Electron 离屏窗口里按时间点截图（借用桌面应用已装的 Vite 和 Electron）。

## 减弱动效

`prefers-reduced-motion: reduce` 下全部动效关闭：直接显示完整标志；开机画面直接显示完整横标，不放星点，加载完成后稍停 0.6s 即结束；状态行只剩静态标志和计时。
