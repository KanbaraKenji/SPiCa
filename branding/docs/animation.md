# Spica 标志动效

标志是纯 SVG，所有动效都是 CSS 关键帧，不需要外部软件；随皮肤变色、适配缩放，并遵守系统「减少动态效果」设置。

- 样式：`packages/brand/src/styles/mark.css`（入口 `@spica/brand/styles.css`）
- 组件：`<SpicaMark state="…">`，组件给 `<svg>` 挂 `spica-mark--<state>`

## 铁律

任何状态下**标志轮廓一像素不动**：动效只动位置、透明度、整体旋转和缩放，不切割、不变形。

## 状态

| state | 场景 | 动作 |
|---|---|---|
| `think` | 等模型生成答复 | **炸开**：瓣向外散开再合拢，星屑从花心飞出，1.7s 一轮 |
| `busy` | 正在流式回复 | **追光**：九片瓣顺时针轮流亮暗 |
| `tool` | 调用工具中 | **咔 120°**：先往回蓄力，再整体转 120°；三片长瓣 120° 对称，循环无缝 |
| `await` | 等工具答复、等人确认 | **脉冲**：轴心向外放两道涟漪，涟漪经过时瓣轻胀 |
| `done` | 完成那一下 | **转一整圈**（一次性） |
| `work-1` / `work-2` / `work-3` | 左上角常驻，后台有任务在跑 | 按负荷分三档：1 档轴呼吸；2 档加三片长瓣星闪；3 档九片全闪、轴变强调色 |
| `idle` | 其他时候 | 静止 |

负荷怎么算由使用方决定（例如并发对话数 + 后台任务数），组件只接档位。

## 点击（`tappable`）

- 每点一下：整体转 120°，轴弹一下、放一圈涟漪。
- 每第三下：一圈冲击波，长瓣闪一下 accent lock 色。
- 累计 39 下起：**accent lock**，长瓣常驻 `--spica-accent-lock`（缺省 `#39C5BB`）。组件触发 `onAccentLock` 回调，要不要记住由使用方决定；也可以用 `accentLocked` 直接控制。

## 回答末尾的状态行

对话忙碌时，状态行接在最后一轮正文末尾：「标志动效 + 本轮计时 + 阶段文案」（思考中… / 正在回复… / 正在调用 X… / 等你确认 X…）。完成后停留约 1.4s，播 `done` 再收起。计时从本轮用户消息发出算起。

## 开机画面：暗处亮起 · 双星环绕

组件 `<SpicaSplash ready={…} onDone={…} theme="dark|light" orbitPeriod={…} caption="v0.1.0" />`，铺满父元素。时间线是纯函数，在 `packages/brand/src/splash.ts`（`splashFrame()` 给出任一时刻的画面状态，`starfield()` 给出背景星点），组件按帧把状态写到 SVG 和画布上。

花标和字标排成大横标居中，花标约占画面高度的 36%；画面是 1280 × 720 的舞台，按窗口等比缩放。

**节拍**：背景星点每颗从中心飘到画面外固定 5 秒（`SPLASH_TIMING.starfieldPeriod`）；双星转一圈 4 秒（`SPLASH_TIMING.orbitPeriod`，组件参数 `orbitPeriod`）。字标的起伏按半圈一拍。

**双星轨道**：像真正的双星一样，两颗星绕共同的中心（花心）转，永远一前一后、相差半圈。轨道是开普勒椭圆（`SPLASH_ORBIT`：半长轴 32 个花标局部单位，花心在焦点上），按开普勒第二定律走：离花心近时快、远时慢，一圈里一快一慢；快慢比是参数（`speedRatio`，缺省 2，即最近点速度是最远点的 2 倍；1 = 匀速圆周）。轨道平面倾斜，投影到屏幕上竖向压到 0.36、整体转 -18°，最近点朝前：星在前面时又快、又大（最多 1.35 倍）、又亮，画在花标上面；在后面时慢、小、暗，画在花标下面。花瓣下面垫一层底色的花形剪影（同一组路径，只当遮挡），所以花瓣暗下去时后面的星也被挡住。星从前面扫过哪片瓣，哪片亮起再慢慢暗下；在后面时只带起三成亮度。

**收尾时间表**（`SPLASH_FINISH`，每一步都是参数，组件参数 `finish` 可逐项覆盖）：

| 步骤 | 什么时候 | 用时 |
|---|---|---|
| 双星和背景平滑加速、螺旋收拢 | ready 起 | 2.0s（缓入，起步加速度 0；双星加到 4 倍转速、背景到 3 倍） |
| 双星合于花心 | ready 后 2.0s | 下面各步从这一刻算起 |
| 九瓣顺时针逐片点亮 | 合一前 0.1s 起，每片间隔 0.11s | 每片 0.45s，九片亮完约 1.33s |
| 轴弹一下 | 合一时 | 0.6s |
| 冲击环扩散 | 合一时 | 1.4s |
| 背景星点回落到平时速度 | 合一时 | 1.5s（平滑） |
| 光从花心掠过字标、逐字点亮 | 合一后 0.9s | 1.5s |
| 停住 | 掠字结束后 | 到合一后 3.6s |
| 整层淡出，然后回调 `onDone` | 合一后 3.6s | 0.4s |

ready 到整层消失共 6.0 秒（`SPLASH_FINISH_AFTER`）。

| 段落 | 动作 |
|---|---|
| 背景（一直在） | 星点从画面中心沿径向飘出屏幕，带短光迹，5 秒一程；四分之一用强调色 |
| 进场 0.2～1.0s | 花和字从暗处浮现 |
| 加载中（循环） | 一蓝一白两颗星在倾斜的开普勒椭圆上绕花标转，4 秒一圈，前面快后面慢 |
| 收尾 | 见上面的时间表 |

任何时刻 ready，收尾都从当前位置接上，不跳帧。Spica 是一对蓝白双星，所以星是一蓝（强调色）一白。

**配色**：暗色底 `#0B0F19`，四角稍压暗，花心和星带淡淡的蓝色光晕。浅色底 `#F7F9FC`，纯色不压暗角，星点用浅蓝细线，**不画任何光晕**（花心光晕、星的光晕整层不画，浅底上会显成一团脏色）。

**预览**：`npm run preview:splash -w @spica/brand -- <输出目录> [dark|light]`，用 Vite 打包 `packages/brand/demo/splash.html`，在 Electron 离屏窗口里按时间点截图（借用桌面应用已装的 Vite 和 Electron）。

## 减弱动效

`prefers-reduced-motion: reduce` 下全部动效关闭：直接显示完整标志；开机画面直接显示完整横标，不放星点，加载完成后稍停 0.6s 即结束；状态行只剩静态标志和计时。
