# Spica 标志动效

标志是纯 SVG，所有动效都是 CSS 关键帧，不需要外部软件；随皮肤变色、适配缩放，并遵守系统「减少动态效果」设置。

- 样式：`packages/brand/src/styles/mark.css`（入口 `@spica/brand/styles.css`）
- 组件：`<SpicaMark state="…">`，组件给 `<svg>` 挂 `spica-mark--<state>`

## 铁律

任何状态下**标志轮廓一像素不动**：动效只动位置、透明度、整体旋转和缩放，不切割、不变形。

## 状态

| state | 场景 | 动作 |
|---|---|---|
| `think` | 等模型生成答复 | **炸开**：瓣向外散开再合拢，星屑从花心飞出，1.7s 一轮 |
| `busy` | 正在流式回复 | **追光**：九片瓣顺时针轮流亮暗 |
| `tool` | 调用工具中 | **咔 120°**：先往回蓄力，再整体转 120°；三片长瓣 120° 对称，循环无缝 |
| `await` | 等工具答复、等人确认 | **脉冲**：轴心向外放两道涟漪，涟漪经过时瓣轻胀 |
| `done` | 完成那一下 | **转一整圈**（一次性） |
| `work-1` / `work-2` / `work-3` | 左上角常驻，后台有任务在跑 | 按负荷分三档：1 档轴呼吸；2 档加三片长瓣星闪；3 档九片全闪、轴变强调色 |
| `idle` | 其他时候 | 静止 |

负荷怎么算由使用方决定（例如并发对话数 + 后台任务数），组件只接档位。

## 点击（`tappable`）

- 每点一下：整体转 120°，轴弹一下、放一圈涟漪。
- 每第三下：一圈冲击波，长瓣闪一下 accent lock 色。
- 累计 39 下起：**accent lock**，长瓣常驻 `--spica-accent-lock`（缺省 `#39C5BB`）。组件触发 `onAccentLock` 回调，要不要记住由使用方决定；也可以用 `accentLocked` 直接控制。

## 回答末尾的状态行

对话忙碌时，状态行接在最后一轮正文末尾：「标志动效 + 本轮计时 + 阶段文案」（思考中… / 正在回复… / 正在调用 X… / 等你确认 X…）。完成后停留约 1.4s，播 `done` 再收起。计时从本轮用户消息发出算起。

## 开机画面：暗处亮起 · 双星环绕

组件 `<SpicaSplash ready={…} onDone={…} theme="dark|light" orbitPeriod={…} caption="v0.1.0" />`，铺满父元素。时间线是纯函数，在 `packages/brand/src/splash.ts`（`splashFrame()` 给出任一时刻的画面状态，`starfield()` 给出背景星点），组件按帧把状态写到 SVG 和画布上。

花标和字标排成大横标居中，花标约占画面高度的 36%；画面是 1280 × 720 的舞台，按窗口等比缩放。

**节拍**：背景星点每颗从中心飘到画面外固定 5 秒（`SPLASH_TIMING.starfieldPeriod`）；双星转一圈 3.5 秒（`SPLASH_TIMING.orbitPeriod`，组件参数 `orbitPeriod`）。字标的起伏按半圈一拍。

**双星轨道**：像真正的双星一样，两颗星绕共同的中心（花心）转，永远一前一后、相差半圈。轨道是开普勒椭圆（`SPLASH_ORBIT`：半长轴 32 个花标局部单位，花心在焦点上），近快远慢，快慢比 `speedRatio` 缺省 2。轨道平面倾斜，最近点朝前：星在前面时又快、又大、又亮，画在花标上面；在后面时慢、小、暗，被花标挡住（花瓣下面垫一层底色剪影）。

**加载中的花和字**：花标九片瓣同一个亮度，跟双星同一个节拍（半圈一拍）呼吸；轴心半透明（约 42%～52%，随呼吸微变），合心那一刻才变实；字标五个字母按同一节拍像波浪一样起伏。花和字都不和星的位置一一对应。双星加载中就带一条短而淡的拖尾。拖尾画成一条连续光带（头宽尾尖、头实尾隐，`trailStyle="streak"`，缺省）；也可以换回一串光点（`trailStyle="dots"`）。光带取的是星真实走过的位置（最近一小段时间），和处在哪一段无关，所以星越快光带越长。光带按「多久以前」切成 16 小段、每段一个透明度（不用沿直线的渐变：尾巴绕成快一圈时，直线渐变的方向每帧大幅摆动，整圈会忽亮忽灭）。合心后星没了，光带的头停在花心、尾巴沿原路继续收进花心，约 0.35 秒收完，不在一帧里消失。

**收尾顺序（定死）**：ready → 加速扩轨（带拖尾）→ 大半径上快转一圈多 → 蓝星转到字标右上方的弯角（这一圈里最慢的一点，像蓄力），从那里顺弧向下、从花右下方兜个小弯收进花心，一路加速 → 细环先行填充 → 扫字 → 停 → 淡出。

**收尾时间表**（`SPLASH_FINISH` 是每一步的时长参数，`splashSchedule()` 算出各步起止；下表是缺省值，从 ready 算起。真实运行里 ready 一到就进收尾；评审视频用 7 秒模拟加载，所以蓝星在视频第 8.20 秒开始扎入、第 8.37 秒合进花心）：

| 步骤 | 开始 | 用时 |
|---|---|---|
| ① 加速扩轨：转速 1 → 6.24 倍，轨道放大到 1.8 倍，同时椭圆平滑变圆（`bigRound: 1`：加载时两颗星各走一条以花心为焦点、彼此错开的椭圆，变圆后走同一条以花心为中心的轨道），拖尾拉长变浓 | 0s | 0.6s |
| ② 大半径上快转约 1.1 圈（`bigSpeed: 6.24`，`bigTurns: 1.063`；ready 到扎入共约 1.7 圈，比只转 3 倍时多约 0.8 圈，扎入时刻不变），结束时蓝星在字标右上方的弯角（`diveAngle: 63`，`diveStar: 'primary'`；前半圈够不到这个方位，取刚从侧面转过来的那一点）。真实运行里加载完成的时刻是随机的，圈数会按 ready 时刻在 1.06 圈上下半圈内微调，保证总由蓝星、从同一方位扎进去（`alignDive` 缺省开） | 0.6s | 约 0.59s |
| ③ 扎心：顺弧向下、从花右下方兜个小弯收进花心。路线形状由 `diveArc: 0.28`（沿轨道方向再走多少，单位圈）、`diveCurl: 1.4`（半径收缩指数，越接近 1 越早往里卷）、`diveSwing`（中途外甩，缺省 0）定；速度按屏幕上的线速度设计：起点接上弯角处的速度，之后只升不降，合心时约是起点的 1.7 倍（`splashDive()` 可查） | 1.19s | 0.175s |
| 双星合于花心、消失；轴心由半透明变实 | 1.37s | 轴心 0.25s |
| ④ 填充（C 细环先行）：两道细环先扩出去，实色随后从花心跟上；轴弹一下 | 1.37s | 1.2s（轴 0.5s） |
| 背景星点：一路缓入加到 3 倍，合一后平滑回落 | 0s / 1.37s | 1.37s / 1.5s |
| ⑤ 扫字：光斑从左到右掠过字标，字由暗变亮、闪一下辉光 | 2.42s | 0.8s |
| 字的辉光回稳 | 3.22s | 0.5s |
| ⑥ 停住 | 3.72s | 1.0s |
| ⑦ 整层淡出，然后回调 `onDone` | 4.72s | 0.4s |

背景星点的放射透视点在窗口正中央（不是花心）；穿过花标区域时被花标挡住。

ready 到整层消失共约 5.1 秒（`SPLASH_FINISH_AFTER`）。浅色版同样的步骤，但不画花心光晕、星的光晕；字的辉光在浅色里是一层清晰的强调色盖在字上，不用模糊（不糊成脏底）。

**跳过**：`skippable` 缺省开，点一下或按任意键，开机画面 0.25 秒淡出后回调 `onDone`（完整版、短版都可以跳）。

**短版**（`mode="brief"`，每天第二次打开起由外壳切换）：完整横标淡入 0.3s、停 0.4s、淡出 0.3s，共 1 秒，不放星点；1 秒到了还没 ready 就停在完整横标上等。时长在 `SPLASH_BRIEF`。

| 段落 | 动作 |
|---|---|
| 背景（一直在） | 星点从窗口正中央沿径向飘出屏幕，带短光迹，5 秒一程；四分之一用强调色 |
| 进场 0.2～1.0s | 花和字从暗处浮现 |
| 加载中（循环） | 一蓝一白两颗星在倾斜的开普勒椭圆上绕花标转，3.5 秒一圈，前面快后面慢；花和字同节拍呼吸 |
| 收尾 | 见上面的时间表 |

任何时刻 ready，收尾都从当前位置接上，不跳帧。Spica 是一对蓝白双星，所以星是一蓝（强调色）一白。

**配色**：暗色底 `#0B0F19`，四角稍压暗，花心和星带淡淡的蓝色光晕，蓝星强调色、伴星近白。浅色底 `#F7F9FC`，纯色不压暗角，星点用浅蓝细线，**不画任何光晕**（花心光晕、星的光晕整层不画，浅底上会显成一团脏色）；双星是实心的，蓝星用强调色（中蓝），伴星用深蓝 `#1B3F7A`，内核和星同色、不挖空。

**预览**：`npm run preview:splash -w @spica/brand -- <输出目录> [dark|light]`，用 Vite 打包 `packages/brand/demo/splash.html`，在 Electron 离屏窗口里按时间点截图（借用桌面应用已装的 Vite 和 Electron）。

## 减弱动效

`prefers-reduced-motion: reduce` 下全部动效关闭：直接显示完整标志；开机画面直接显示完整横标，不放星点，加载完成后稍停 0.6s 即结束；状态行只剩静态标志和计时。

## 交接（2026-11-09，开机动画定稿）

定稿过程：第十四版他全按推荐（扎入一路加速、路线乙 弧线收心、连续光带拖尾、扎入前转弯那一下放慢保留），备注原话：「建议在保持现在的时间节点不变的情况下，把加速转圈多加一圈」。

最终版：时刻不动（评审视频 7.0 加速起、7.6 到位、8.20 扎入、8.37 合心，之后各段同前），加速段转速 3 → 6.65 倍，ready 到扎入从约 0.85 圈变成约 1.8 圈。转速一高，蓝星在原扎入点（72°）已经很快且还在猛加速，顺乙的弧线 0.175 秒内没法再「只升不降」，所以扎入点挪到字标右上方的弯角（63°，这一圈最慢的那一点，正好是他选了保留的「蓄力」），路线把 `diveArc` 从 0.15 加到 0.22，还原乙「从花右下方兜个小弯收进花心」的样子；扎入段只升不降，终点约是起点的 2.8 倍（第十四版是 3.6 倍：起点更慢了，终点绝对速度差不多）。光带拖尾随速度拉长，大半径段像彗尾。

定稿视频：`docs/screenshots/brand/boot-final-dark.mp4`、`boot-final-light.mp4`（1280 × 720，每秒 60 帧，前 7 秒模拟加载），轨迹图 `boot-final-trajectory.png`。其余评审视频已从仓库删掉（历史不重写），留档在仓库外 `K:\spica-review\brand\`。

故意没做：没有把 ready 时刻不同导致的圈数差（在 1.13 圈上下半圈内）拉平——那是为了保证每次都从同一方位扎入；浅色版没有单独调光带颜色。

补记（同日，最终版「还不行」）：他原话「这帧和下一帧感觉不连贯，拖尾一下就消失了，不知道是因为加速曲线不对还是渲染问题？」「动画不连贯」「从我的角度来看，感觉轨道本身跳变了2次，很不自然」。逐帧复现出两处，都是拖尾渲染问题，不是轨道：① 合心那一帧，约 650 像素长的光带整条消失（8.367 → 8.383 秒）；② 光带用的是「头到尾一条直线」的渐变，尾巴绕成快一圈时头尾挨得很近，渐变方向每帧乱摆，整圈光带忽亮忽灭（7.800 → 7.833 秒）。已改成按小段定透明度、合心后收进花心。轨道半径、转速、每帧位移在各段交界处都连续（逐帧检查已并入测试：位移变化每帧小于 16 像素，光带每帧最多收短 80 像素、亮度总量每帧变化不超过最亮时的 25%）。同类检查：别处没有沿曲线的直线渐变（花心、星的光晕是径向渐变，字的辉光是模糊，不受影响）。

可选（他没要求，先不做）：大半径段 6.65 倍转速下，开普勒近快远慢加上透视，蓝星每帧移动在 20～75 像素之间起伏；若修好后他仍觉得 7.6～8.2 秒顿挫，最省事的做法是在扩轨时把偏心率逐渐降到 0（一个参数），再重调扎入点。

补记（2026-11-10，「三圈的轨迹不和谐」）：他原话「三圈的轨迹不和谐，虽然拖尾连贯了，但是感觉很奇怪」「我建议你把三次的轨迹画出来就知道为什么奇怪了」。把 7.0～8.37 秒两颗星的轨迹画出来后看清了：开普勒椭圆的花心在焦点上，蓝星那条偏右上、白星那条偏左下，两条椭圆彼此错开；放大 1.8 倍后交叉成几圈乱线，中心也不在花心。改成扩轨时椭圆平滑变圆（`bigRound: 1`），之后两颗星走同一条以花心为中心的轨道，倾角、长轴方向全程不变；测试检查扩轨后两星始终关于花心对称、都落在同一个以花心为中心的椭圆上。转速随之 6.65 → 6.24 倍（扎入时刻不变），扎入弧 0.22 → 0.28（变圆后扎入起点更快，弧长一点才能一路加速）。另加两个可调参数 `bigUniform`（近快远慢 → 匀角速度）、`bigRoll`（倾角渐变），缺省不启用。
