# 完成状态图标（带圈对钩）：要求说明

> 纯描述。成品是 `icons/spica-check.svg`（单色，颜色随调用处）；`icons/spica-check-preview.svg` 是填了绿色的预览版，只用来看效果，不要直接引用。

## 用在哪里

- 所有表示「完成 / 成功」的状态位置，例如：任务或步骤完成、Agent 子会话跑完、卡片的完成态。
- 用户对这个图标很满意，**原样使用，不要换成图标库里现成的带圈对钩**。现成版本的勾偏小、顶点偏右上，观感不一样。

## 造型

- 一个圆圈加一个大对钩，24×24 网格。
- 对钩很大：
  - 短臂从圈内左侧起笔。
  - 拐点落在圆心正下方。
  - 长臂斜向右上，一直伸出圆圈之外。
- 圆圈在长臂穿出的地方断开。断口是**切角**：两个断面都和长臂平行，不是圆头。
- 线条端点和拐角都是圆头，只有圆圈的断口例外。

## 粗细

- 线宽 2.5，比界面上普通线性图标的 2 粗。
- 规则：带圈的**状态图标**（完成、警告、错误、进行中这一族）统一用 2.5；菜单、按钮这类**操作图标**保持常规粗细。两种粗细形成对比，状态更显眼。
- 同一族的其他带圈状态图标（警告、错误等）请按同样的粗细、圆圈大小来做，跟这个对钩保持一套。

## 颜色和尺寸

- 单色。颜色取当前皮肤的**成功色**，换皮肤跟着变，不写死绿色。
- 常用尺寸 15–16px，跟在文字旁边。深色、浅色背景下都要看得清。
