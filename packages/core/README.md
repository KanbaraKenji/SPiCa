# @spica/core

The Spica agent core: the agent loop, model providers, built-in tools (web search,
read / find / write files, ...) and the multi-agent runtime (top-level agent,
project-manager agents, sub-agents).

Status: empty placeholder. The core is written from scratch in this package and runs
in plain Node (no Electron APIs), so it can be driven from the desktop app, the MCP
server or tests alike.
